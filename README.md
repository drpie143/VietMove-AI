# VietMove AI Landing Page

A single-file landing page suitable for a project website field when applying for transport API/affiliate access.

## Before publishing

Open `index.html` and change:

- `VietMove AI` → your real project name
- `khoaanhngo113@gmail.com` → your email address
- Project text if you want to narrow or expand the scope

## Fast deployment options

### GitHub Pages
1. Create a new public repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. GitHub will provide a public URL such as `https://username.github.io/repository-name/`.

### Vercel
1. Create a new Git repository containing `index.html`.
2. Import it into Vercel.
3. No framework is required; deploy as a static site.
4. Use the generated `*.vercel.app` URL in the partner-registration form.
